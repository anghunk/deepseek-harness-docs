## 主要变更

### 架构与术语
- **PTC mode 重命名**：Code Mode 重命名为 PTC mode（Process-Tool-Call mode），配置文件值、预设目录/ID、演示、分发 waterfall、提示词规则均已更新；持久化词汇保持不变
- **Profile 系统扩展**：新增 `dsh-sdk-app`、`dsh-sdk-minimal`、`dsh-acp-app` 三个 bundle；profile 系统成为 dsh 作为唯一 Node 应用启动器的统一入口
- **Agent Teams（实验性）**：新增 `dsh-agent-teams-cli` 和 `dsh-agent-teams-web` 两个实验性 profile，支持多 Agent 协作

### 核心子系统
- **会话持久化优化**：
  - 格式迁移管道（`SESSION_FORMAT_VERSION` v0→v1），解码器管道自动应用迁移
  - 打包助手历史传输（packed assistant chunks），多个连续 chunk 打包为单个传输单元
  - Per-record 存储布局，会话拆分为多个小记录文件，支持原子写入与并发读取
  - 投影缓存（projection cache），每个会话独立缓存派生投影，加速冷启动
- **子代理增强**：
  - 浏览器控制迁移到 Remote（`feat(subagent): migrate browser control to Remote`）
  - 子代理模型选择（`feat(subagent): authorize selectable child models`），支持动态路由到不同 LLM 提供者

### Web 客户端
- **浏览器 Worker 运行时（实验性）**：`packages/experimental/webworker-runtime` 与 `webworker-packer` 在浏览器 worker 线程中运行完整 dsh 宿主环境，配合 VFS 镜像打包器
- **Cordis Inspector**：通过 Chrome DevTools Protocol (CDP) 暴露 Cordis 插件树，支持 DOM 投影、Network 代理、Worker 服务
- **词法 Composer**：输入框从 textarea 栈迁移到词法编辑器，支持结构化引用的内联渲染与编辑
- **Streaming Fence 高亮**：流式栅栏增量高亮，配合 Turn rail 提供长对话导航
- **浏览器认证强化**：WebSocket upgrade 使用签名浏览器 cookie 认证，统一安全模型

### 其他
- **新包**：`experimental/webworker-runtime`、`experimental/webworker-packer`、`inspector`、`team`、`webhook`、`webhook-github`、`deepseek`（session log upload）
- **仓库规模**：业务包从 50+ 增长到 60+
