## 文档更新详情

### part3-core/ch8-boot-chain.md

- **新增 8.8 节"Profile 解析模式"**：说明 `ProfileResolutionMode = 'link' | 'dual' | 'runtime'` 三种解析模式的工作机制
  - `link` 模式（默认）：物化 `.dsh-module-fallback/` 目录下的符号链接，保持向后兼容
  - `runtime` 模式：通过 Node 的 ESM 与 CommonJS 解析器直接安装 generation，不创建磁盘链接
  - `dual` 模式：物化链接表并与 Node 的磁盘结果对比验证
  - 说明 `ctx.pluginPackages` 服务暴露同一代的包元数据
  - 说明 Worker 构建横幅导入 `profile-resolution-bootstrap` 并在 isolate 中安装 generation

- **更新 8.9 节小结**：新增 Profile 解析三模式说明，强调默认 link 模式保持向后兼容

### part3-core/ch9-profile-bundle.md

- **新增 9.9 节"原生缓存与 Worker 隔离"**：说明 `0.1.6-alpha.1` 的原生缓存管理变更
  - 原生缓存生命周期由 addon 管理而非 profile-resolution 服务自行管理
  - Windows 平台上 Worker 环境暂时提供私有的缓存目录（`dsh-profile-resolution-native-*`）
  - Worker 构建横幅导入 `@deepseek-ai/dsh-app-boot/worker/profile-resolution-bootstrap`
  - 每个 Worker 在自己的 isolate 中安装结构化克隆的 generation

- **更新 9.10 节小结**：新增原生缓存管理与 Worker 隔离说明

### part4-web/ch17-web-client.md

- **新增 17.27 节"Sticky Headers 与 Compaction Banner 改进"**：说明 `0.1.6-alpha.1` 的长对话滚动体验改进
  - `feat(web): pin Think and compaction headers sticky while scrolling`：Think 与 compaction 的 section header 钉在滚动视口顶部
  - `fix(web): hold a compaction summary's code banner below the pinned header`：修复 compaction 摘要中 fenced code block 的 Copy 横幅与钉住 header 重叠的问题
  - 横幅停在 header band 下方，钉住 header 的边角改为方形（`border-radius: 0`）
  - 说明该修复与 17.16 中的 `perf(ui-chat): contain collapsed reasoning layout` 配合优化长推理链可读性

- **更新 17.28 节设计亮点小结**：新增第 21 项"Sticky Headers 与 compaction code banner 位置修复"
