## 主要变更

### Web 客户端（ch17）

- **Sidebar 图片预览**（`8870a13aa9 feat(sidebar): preview image files`）：右侧 Sidebar 新增第四个随包交付的 tab 类型——图片预览（`ui-sidebar-imagepreview`，kind=`image`），认领常见图片扩展名（`.png`、`.jpg`、`.jpeg`、`.gif`、`.svg`、`.webp`），经 `useResource<'file'>` 读元数据并通过 `<img>` 标签直接渲染，支持缩放与平移交互，适配亮/暗主题。
- **显式文件交付**（`9b308c9568 Merge PR #3819 feat/artifact-file-actions` 系列）：引入 `packages/fs/tool-present`（Host 工具，拥有执行、不可变快照、交付类型）与 `packages/client/ui-deliverables`（客户端插件，拥有认证快照操作与浏览器渲染）。成功最终 `tools/result` 通知时追加 `deliverables/presented` 事件到调用方 Session；下载与打开请求按当前查看的 Session、事件序号与文件索引授权引用。Session ZIP 保留交付事件但不收集 attachment 字节。
- **Webworker 文件句柄改进**（`60a3d0fbc2 fix(webworker): support file handle chmod`、`a7bd71e024 fix(webworker): preserve bigint file handle identity`）：worker 内 FileHandle 支持 `chmod(mode)` 操作，bigint 身份在 `postMessage` 传输两侧保持同一引用（基于内部 bigint id 的 WeakMap 注册表）。
- **Mermaid/Graphviz/SVG/HTML 预览已回滚**（`7588e1ea11 Merge PR #3901 revert-3710-feat/mermaid-preview`）：PR #3710 合并后又被 PR #3901 完全回滚，最终代码不包含该功能，文档不作记录。

### Session 日志（ch10）

- **Session 格式状态参考**（`cd95dda1bd Merge PR #3866 docs/session-format-authority`）：`docs/session-format-status.md`（双语）作为发布状态真源，拥有 `latestReleasedVersion` 与 `evidenceTag` 记录；`SESSION_FORMAT_VERSION` 常量拥有工作区写入器版本号。文档标准检查校验记录结构、双语一致性、证据链接一致性及本地发布版本与写入器版本的大小关系。

### 子代理（ch16）

- **Agent Teams 包公开发布**（`16953f2b8e Merge PR #3884 feat/public-experimental-agent-team`、`63187de80f release: publish experimental Agent Teams packages`）：`packages/experimental/` 下的五个 Agent Teams 包从私有 workspace 包变更为公开发布的实验性包，保留 `@deepseek-ai/dsh-experimental-*` 命名前缀并加入 dsh 发布系列。用户可直接从 npm 安装完整 Team 组合，但公开发布不代表稳定或默认受支持。
