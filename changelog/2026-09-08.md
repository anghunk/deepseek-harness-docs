### 变更总结

本次上游更新引入了 Web 客户端的**右侧 Sidebar 系统**，这是自词法 Composer 以来最大的 UI 架构变化。核心交付包括：

1. **客户端资源模型**（`useResource`）：统一的"有名东西"读取抽象，地址是身份，订阅是状态，多个观察者共享同一份订阅
2. **工作区文件服务**：把 Host 侧的文件操作拆成元数据面与内容面，底层提供有界字节范围读取（本地与沙箱共享合约）
3. **右侧 Sidebar**：第三列可停靠 tab pane，tab 类型注册表按地址/档位认领，三个随包类型（引导页、文本预览、文件树）演示 keyed slot + chain fallback + 档位认领的完整模式
4. **产品行为变化**：Details 列移除，文件打开改道 Sidebar；会话 Header 新增 corner slot 承载 Sidebar 切换按钮

这些变化为插件作者提供了完整的 tab 类型注册样板：查看器（textpreview）、页类型（files）、替换接缝（guide）各有可照抄的模式。
